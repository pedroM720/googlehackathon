# Project Instructions

## Priorities
- Optimize for a polished, working hackathon demo.
- Prefer the simplest reliable implementation.
- Follow the agreed product scope and Figma design.
- Do not add features without approval.

## Workflow
- Inspect the existing project before editing.
- Make small, coherent changes.
- Run relevant tests and the production build after changes.
- Verify integrations with real responses.
- Report errors, assumptions, and incomplete work honestly.

## Security
- Never hardcode API keys or secrets.
- Keep secrets in environment variables.
- Never commit .env files.
- Validate external API responses and handle failures.
- Ask before destructive commands or changes to shared infrastructure.

## Completion
- Explain what changed and how to run it.
- List tests actually executed and their results.
- Identify any remaining issues or unverified behavior.
