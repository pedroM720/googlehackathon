# nook

Landing page for Nook, built with React + Vite. Brand and style rules live in [identity.md](identity.md). The final logo is `public/nook-logo.png` and `public/nook-logo.svg`, and the React component `src/components/Wordmark.jsx`.

## Run it

```bash
npm install
npm run dev      # local dev server
npm run build    # production build into dist/
npm run preview  # serve the production build
npm run lint
```

Deploys to Vercel as a standard Vite project (build command `npm run build`, output `dist`).
